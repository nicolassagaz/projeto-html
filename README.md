# Projeto Frontend - Jornada Dev

Projeto desenvolvido durante minha transição da área de suporte técnico para desenvolvimento de software.

O objetivo deste projeto é praticar fundamentos do desenvolvimento frontend utilizando HTML, CSS e JavaScript puro, evoluindo gradualmente para aplicações web mais interativas e organizadas.

---

## Funcionalidades

- Estrutura HTML semântica
- Layout responsivo
- Flexbox
- Componentes visuais modernos
- Manipulação de DOM
- Adição dinâmica de objetivos
- Remoção dinâmica de objetivos
- Validação de formulário
- Feedback visual de erros
- Alteração dinâmica de estilos
- Interatividade com JavaScript

---

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
